# CRUD de Esportes

Aplicação web em Flask + SQLite + SQLAlchemy com CRUD completo.

## Funcionalidades

- Listar esportes
- Cadastrar esporte
- Visualizar dados na tabela
- Editar esporte
- Excluir esporte
- Banco SQLite criado automaticamente

## Como executar

1. Crie e ative um ambiente virtual (opcional, mas recomendado):

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

2. Instale as dependências:

```bash
pip install -r requirements.txt
```

3. Execute:

```bash
python app.py
```

4. Abra no navegador:

http://127.0.0.1:5000/

O arquivo `esportes.db` será criado automaticamente na primeira execução.
